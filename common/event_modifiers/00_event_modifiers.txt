# 00_event_modifiers.txt (vanilla name: index only)
#
# This file keeps the name of vanilla's 00_event_modifiers.txt so that it
# replaces it: common/event_modifiers has no replace_path, so every vanilla
# file without a mod file of the same name would still load. The mod's event
# modifiers are in the WHG_ files of this folder, one per subject. The same
# goes for 01_event_modifiers_LT.txt.
#
# Files:
#   WHG_bretonnia_event_modifiers.txt (104): Bretonnia: knights, the Lady, the
#     Grail, tourneys
#   WHG_chaos_event_modifiers.txt (182): Chaos: the four gods and Undivided,
#     cults, daemons, the Doom, mutation, beastmen, skaven, Norsca
#   WHG_character_event_modifiers.txt (374): characters: health, personality,
#     lifestyle, family, love, education, mounts and pets
#   WHG_court_event_modifiers.txt (120): the court: council, offices, intrigue,
#     plots, prison, friends and rivals
#   WHG_dwarf_event_modifiers.txt (115): the Dawi: holds, grudges, engineers,
#     runesmiths, the Elder Council, Chaos Dwarfs
#   WHG_east_event_modifiers.txt (79): the East: Cathay, the Ivory Road, the
#     steppe, off-map powers
#   WHG_elves_event_modifiers.txt (36): the elves: Ulthuan (Asur), Athel Loren
#     (Asrai), Naggaroth (Druchii)
#   WHG_empire_event_modifiers.txt (156): the Empire: Electors, colleges, witch
#     hunters, the cults of Sigmar, Verena and Morr
#   WHG_engine_event_modifiers.txt (6): applied by the game itself; never
#     rename
#   WHG_faith_event_modifiers.txt (286): faith: piety, heresy, saints, holy
#     wars, doctrines, monks, coronations
#   WHG_greenskin_event_modifiers.txt (40): greenskins and ogres: the Waaagh!,
#     tribes, warbands
#   WHG_kislev_event_modifiers.txt (123): Kislev: the Ice Queen, Praag,
#     Erengrad, the Bulwark, oblasts and stanitsas
#   WHG_legend_event_modifiers.txt (40): ambitions, deeds of legend, great
#     hunts, artifacts, books and debates
#   WHG_magic_event_modifiers.txt (69): magic: the Winds, the lores, wizards,
#     stars and seers
#   WHG_realm_event_modifiers.txt (201): the realm: holdings, provinces, laws,
#     economy, slaves, republics, revolts, wonders
#   WHG_sea_event_modifiers.txt (63): the sea: ships, voyages, pirates, the sea
#     societies
#   WHG_society_event_modifiers.txt (99): societies and orders that are not
#     tied to one race
#   WHG_south_event_modifiers.txt (93): the South and the West: Araby, Lustria,
#     Albion, the Southlands, colonies and ventures
#   WHG_undead_event_modifiers.txt (122): the undead: vampires, necromancers,
#     Mousillon, the Tomb Kings of Nehekhara
#   WHG_vanilla_event_modifiers.txt (212): vanilla ones the mod does not use,
#     kept for salvage
#   WHG_war_event_modifiers.txt (116): war: battles, armies, mercenaries,
#     raids, duels and the armoury
