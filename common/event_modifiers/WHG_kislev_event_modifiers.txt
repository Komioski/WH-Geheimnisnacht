# Kislev event modifiers (WHG_kislev_event_modifiers.txt)
#
# Covers Kislev: the Ice Queen, Praag, Erengrad, the Bulwark, oblasts and
# stanitsas.
#
# Event modifiers are named bundles of modifiers that scripts put on a
# character, province, holding, title or society and take off again
# (add_character_modifier, add_province_modifier, has_character_modifier...).
# Each one has an icon (a frame of gfx/interface/modifier_icons.dds; the list
# is in WHG_engine_event_modifiers.txt), may have is_visible (ROOT is the
# viewer, FROM the holder; hidden_trait, visible_trait and the religion
# variants are the mod's scripted triggers in common/scripted_triggers), and
# then any character or province modifiers. A key is global: the file it is
# in does not matter, but it must be defined only once in the mod. The file
# index is in 00_event_modifiers.txt.
#
# Each entry starts with its name in game (or "Hidden" when it has none) and
# the files that use it, most uses first.
