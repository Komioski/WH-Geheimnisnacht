# Units modifier definitions (WHG_unit_modifier_definitions.txt)
#
# Covers special troops (the troop itself and its attack, defence and morale)
# and the armoury buffs.
#
# Modifier definitions declare modifiers that the game builds from the name
# of another object, so that they work and show in tooltips: a special
# troop (<troop>, <troop>_offensive, _defensive, _morale), opinion of a
# culture, culture group, religion or religion group (<name>_opinion), of
# a trait (<trait>_opinion: others' opinion of its holder; opinion_of_<trait>:
# its holder's opinion of others), an off-map currency, or a text-only
# effect a bloodline or building shows. Keys: show_as_percent, is_good,
# is_monthly, is_hidden, max_decimals, show_value. The loc key is the name
# itself. See _documentation.info; the file index is in
# 00_modifier_definitions.txt.
