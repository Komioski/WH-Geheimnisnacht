# A character's life: on_actions (WHG_character_on_actions.txt)
#
# Birth, childhood and the growing-up pulses, adulthood, marriage and
# divorce, prison, exile, murder, death and a character changing culture,
# master, host or nickname.
#
# How on_actions work: the game fires each on_action at a fixed moment and
# ROOT gets the listed events. Every event in `events = { }` is checked;
# `random_events = { }` picks one valid event by weight, and each named
# sub-list (`name = { delay = N  w = ns.id }`) picks one of its own, so it
# never changes the odds of the others. A `0` entry is the chance of no
# event. The same on_action may appear in several files and the lists add
# up, but in this mod every on_action is written exactly once, so one
# search finds everything that fires on it. The file index is in
# 00_on_actions.txt.
#
# Each line is an event id with a comment: its title from the event's doc
# comment, then the event file, e.g. "Warpstone from the mines
# (WHG_skaven_events)".
#
# On_actions here, in order:
#   on_yearly_childhood_pulse on_failed_assassination
#   on_failed_assassination_disc on_assassination on_assassination_disc
#   on_birth on_adulthood on_adolescence on_post_birth
#   on_post_birth_stillbirth on_pregnancy on_marriage
#   on_become_imprisoned_any_reason on_became_imprisoned
#   on_avoided_imprison_fled_country on_released_from_prison on_executed
#   on_exiled on_death on_letter_event_message on_character_event_message
#   on_forced_consort on_unlanded on_character_convert_culture
#   on_acquire_nickname on_divorce on_feud_started on_blood_brother_death
#   on_focus_selected on_employer_change on_host_change on_childhood_pulse
#   on_adolescence_pulse
