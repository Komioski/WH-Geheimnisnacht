# War, battle and plunder: on_actions (WHG_war_on_actions.txt)
#
# Wars declared and ended, battles, sieges, looting and raids, the combat
# and siege pulses, armies on the move, rebels and mercenaries.
#
# How on_actions work: the game fires each on_action at a fixed moment and
# ROOT gets the listed events. Every event in `events = { }` is checked;
# `random_events = { }` picks one valid event by weight, and each named
# sub-list (`name = { delay = N  w = ns.id }`) picks one of its own, so it
# never changes the odds of the others. A `0` entry is the chance of no
# event. The same on_action may appear in several files and the lists add
# up, but in this mod every on_action is written exactly once, so one
# search finds everything that fires on it. The file index is in
# 00_on_actions.txt.
#
# Each line is an event id with a comment: its title from the event's doc
# comment, then the event file, e.g. "Warpstone from the mines
# (WHG_skaven_events)".
#
# On_actions here, in order:
#   on_combat_pulse on_siege_pulse on_battle_won on_major_battle_won
#   on_battle_won_leader on_major_battle_won_leader on_battle_won_owner
#   on_battle_lost on_major_battle_lost on_battle_lost_leader
#   on_major_battle_lost_leader on_battle_lost_owner on_siege_won_leader
#   on_siege_lost_leader on_siege_over_winner on_siege_over_winner_trade_post
#   on_siege_over_loc_chars on_avoided_imprison_started_war
#   on_prepared_invasion_monthly on_prepared_invasion_aborts
#   on_prepared_invasion_expires on_merc_rampage on_merc_leave
#   on_merc_turn_coat_from on_merc_turn_coat_to on_loot_settlement
#   on_loot_province on_warleader_death on_rebel_revolt on_defect_to_rebels
#   on_defect_from_rebels on_settlement_looted on_navy_returns_with_loot
#   on_war_started on_war_ended_victory on_war_ended_whitepeace
#   on_war_ended_defeat on_war_ended_invalid on_ai_end_raid on_mercenary_hired
#   on_mercenary_dismissed on_mercenary_captain_replacement
#   on_revoke_attempted_started_war on_retract_vassal_attempted_started_war
#   on_absorb_clan_attempted_started_war on_split_clan_attempted_started_war
#   on_unit_entering_province on_command_unit on_command_sub_unit
#   on_wonder_loot_start on_wonder_stage_loot_finish
