# 00_opinion_modifiers.txt (vanilla name: index only)
#
# This file keeps the name of vanilla's 00_opinion_modifiers.txt so that it
# replaces it: common/opinion_modifiers has no replace_path, so every vanilla
# file without a mod file of the same name would still load. The mod's opinion
# modifiers are in the WHG_ files of this folder, one per subject. The same
# goes for 01_lunatic.txt.
#
# Files:
#   WHG_bretonnia_opinion_modifiers.txt (23): Bretonnia: knights, the Lady, the
#     Grail, tourneys
#   WHG_chaos_opinion_modifiers.txt (70): Chaos: the four gods and Undivided,
#     cults, daemons, the Doom, mutation, beastmen, skaven, Norsca
#   WHG_character_opinion_modifiers.txt (236): characters: health, personality,
#     lifestyle, family, love, education, mounts and pets
#   WHG_court_opinion_modifiers.txt (121): the court: council, offices,
#     intrigue, plots, prison, friends and rivals
#   WHG_dwarf_opinion_modifiers.txt (29): the Dawi: holds, grudges, engineers,
#     runesmiths, the Elder Council, Chaos Dwarfs
#   WHG_east_opinion_modifiers.txt (11): the East: Cathay, the Ivory Road, the
#     steppe, off-map powers
#   WHG_elves_opinion_modifiers.txt (30): the elves: Ulthuan (Asur), Athel
#     Loren (Asrai), Naggaroth (Druchii)
#   WHG_empire_opinion_modifiers.txt (62): the Empire: Electors, colleges,
#     witch hunters, the cults of Sigmar, Verena and Morr
#   WHG_engine_opinion_modifiers.txt (197): applied by the game itself; never
#     rename
#   WHG_faith_opinion_modifiers.txt (113): faith: piety, heresy, saints, holy
#     wars, doctrines, monks, coronations
#   WHG_greenskin_opinion_modifiers.txt (5): greenskins and ogres: the Waaagh!,
#     tribes, warbands
#   WHG_kislev_opinion_modifiers.txt (68): Kislev: the Ice Queen, Praag,
#     Erengrad, the Bulwark, oblasts and stanitsas
#   WHG_legend_opinion_modifiers.txt (29): ambitions, deeds of legend, great
#     hunts, artifacts, books and debates
#   WHG_magic_opinion_modifiers.txt (5): magic: the Winds, the lores, wizards,
#     stars and seers
#   WHG_realm_opinion_modifiers.txt (79): the realm: holdings, provinces, laws,
#     economy, slaves, republics, revolts, wonders
#   WHG_sea_opinion_modifiers.txt (11): the sea: ships, voyages, pirates, the
#     sea societies
#   WHG_society_opinion_modifiers.txt (24): societies and orders that are not
#     tied to one race
#   WHG_south_opinion_modifiers.txt (21): the South and the West: Araby,
#     Lustria, Albion, the Southlands, colonies and ventures
#   WHG_undead_opinion_modifiers.txt (23): the undead: vampires, necromancers,
#     Mousillon, the Tomb Kings of Nehekhara
#   WHG_vanilla_opinion_modifiers.txt (82): vanilla ones the mod does not use,
#     kept for salvage
#   WHG_war_opinion_modifiers.txt (47): war: battles, armies, mercenaries,
#     raids, duels and the armoury
