# South opinion modifiers (WHG_south_opinion_modifiers.txt)
#
# Covers the South and the West: Araby, Lustria, Albion, the Southlands,
# colonies and ventures.
#
# Opinion modifiers are what one character thinks of another for a reason
# (opinion, add_opinion, reverse_opinion, has_opinion_modifier). Keys:
# opinion (the value), months or years (how long it lasts; none means until
# removed), inherit = yes (heirs keep it), crime = yes (counts as a foe for
# is_foe), the reasons it gives to act without penalty (prison_reason,
# banish_reason, execute_reason, revoke_reason, divorce_reason), enemy,
# disable_non_aggression_pacts, non_aggression_pact, obedient and
# non_interference. A key is global: the file does not matter, but it must
# be defined only once. The file index is in 00_opinion_modifiers.txt.
#
# Each entry starts with its name in game (as shown in the opinion
# breakdown) and the files that use it, most uses first.
