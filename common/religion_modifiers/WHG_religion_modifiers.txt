###############################################################################
# WHG_religion_modifiers.txt - religious authority modifiers
#
# Each entry changes the authority of a whole faith for a number of years.
# They are given out with religion_authority = { modifier = <key> }, from an
# event, decision, effect or casus belli. The name shown in game is the
# localisation key of the same name.
#
# This folder has no replace_path: 00_religion_modifiers.txt keeps the vanilla
# name as an empty stub so the vanilla copy is not loaded twice.
#
# Sections:
#   Applied by the engine
#   War results
#   Heads of faith, clergy and conversion
#   Rites and doctrine
#   Ambitions
#   Warhammer
#   Unused vanilla
###############################################################################
