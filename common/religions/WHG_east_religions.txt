# East religions (WHG_east_religions.txt)
#
# Cathay's Dragon gods and the Ogres' Great Maw.
#
# How the game reads this folder (replace_path, so only the mod's files
# load): each top-level block is a religion group, and each block inside it
# with an icon is a religion. Group keys (colour, graphical_culture,
# crusade_cb, playable, hostile_within_group, ai_*) apply to every religion in
# the group unless the religion sets its own. Faith names and descriptions
# are localisation keys (<religion>, <religion>_DESC); god names, scripture,
# priest title and crusade name are keys too. A religion-specific opinion
# (sigmarite_opinion = 5) must also be defined in
# common/modifier_definitions/WHG_opinion_modifier_definitions.txt.
# "intermarry" matters across groups (marriage within a group is always
# allowed) and should be written on both sides. "parent" makes a religion a
# heresy of another; "reformed" names the reformed version of a pagan faith.
#
# Groups and religions:
#   oriental_gods_group: draconite
#   great_maw_group: great_maw, fire_mouth
