# 00_scripted_effects.txt (vanilla name: index only)
#
# This file keeps the name of vanilla's 00_scripted_effects.txt so that it
# replaces it: common/scripted_effects has no replace_path, so every vanilla
# file without a mod file of the same name would still load. The other vanilla-
# name files here (01_scripted_effects_duels.txt,
# 02_scripted_effects_alternate_start.txt, 03_scripted_effects_sainthood.txt,
# 04_scripted_effects_crusades.txt, 05_scripted_effects_competitions.txt,
# 06_scripted_effects_legendary_bloodlines.txt,
# 07_scripted_effects_holy_orders.txt, 08_scripted_effects_wonders.txt) are
# empty for the same reason. The mod's scripted effects are in the WHG_ files
# of this folder, one per subject.
#
# Files:
#   WHG_bretonnia_effects.txt (27): Bretonnia: knights, the Lady, the Grail,
#     tourneys
#   WHG_chaos_effects.txt (212): Chaos: the four gods and Undivided, cults,
#     daemons, the Doom, mutation, beastmen, skaven, Norsca
#   WHG_character_effects.txt (272): characters: health, personality,
#     lifestyle, family, love, education, mounts and pets
#   WHG_court_effects.txt (58): the court: council, offices, intrigue, plots,
#     prison, friends and rivals
#   WHG_dwarf_effects.txt (70): the Dawi: holds, grudges, engineers,
#     runesmiths, the Elder Council, Chaos Dwarfs
#   WHG_east_effects.txt (163): the East: Cathay, the Ivory Road, the steppe,
#     off-map powers
#   WHG_elves_effects.txt (29): the elves: Ulthuan (Asur), Athel Loren (Asrai),
#     Naggaroth (Druchii)
#   WHG_empire_effects.txt (122): the Empire: Electors, colleges, witch
#     hunters, the cults of Sigmar, Verena and Morr
#   WHG_engine_effects.txt (10): what the game itself calls: hard-coded
#     interaction and crusade buttons, portrait triggers read by
#     interface/portraits
#   WHG_faith_effects.txt (169): faith: piety, heresy, saints, holy wars,
#     doctrines, monks, coronations, competitions of the faiths
#   WHG_game_rule_effects.txt (11): the mod's game rules
#   WHG_greenskin_effects.txt (14): greenskins and ogres: the Waaagh!, tribes,
#     warbosses
#   WHG_kislev_effects.txt (17): Kislev: the Ice Queen, Praag, Erengrad, the
#     Bulwark, oblasts and stanitsas
#   WHG_legend_effects.txt (61): ambitions, deeds of legend, great hunts,
#     artifacts, books and debates
#   WHG_magic_effects.txt (74): magic: the Winds, the lores, wizards, stars and
#     seers
#   WHG_race_effects.txt (7): races: racial traits, which faiths and cultures
#     fit which race, races without women
#   WHG_realm_effects.txt (58): the realm: holdings, provinces, laws, economy,
#     slaves, republics, revolts, wonders, alternate start
#   WHG_sea_effects.txt (62): the sea: ships, voyages, pirates, the sea
#     societies
#   WHG_society_effects.txt (122): societies: warrior lodges and warbands, the
#     assassins, bloodlines of the orders, other orders not tied to one race
#   WHG_south_effects.txt (55): the South and the West: Araby, Lustria, Albion,
#     the Southlands, colonies and ventures
#   WHG_undead_effects.txt (67): the undead: vampires, necromancers, Mousillon,
#     the Tomb Kings of Nehekhara
#   WHG_vanilla_effects.txt (104): vanilla definitions that nothing in the mod
#     uses
#   WHG_war_effects.txt (110): war: battles, armies, mercenaries, raids, duels,
#     crusade wars and the armoury
