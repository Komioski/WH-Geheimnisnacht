# 00_scripted_score_values.txt (vanilla name: index only)
#
# This file keeps the name of vanilla's 00_scripted_score_values.txt so that it
# replaces it: common/scripted_score_values has no replace_path, so every
# vanilla file without a mod file of the same name would still load. The other
# vanilla-name files here (01_scripted_score_values_papal_ai_behavior.txt,
# 02_scripted_score_values_wonders.txt) are empty for the same reason. The
# mod's scripted score values are in the WHG_ files of this folder, one per
# subject.
#
# Files:
#   WHG_ai_score_values.txt (32): weights for AI choices and random picks: who
#     makes a good soldier, recruit, target or heir
#   WHG_vanilla_score_values.txt (21): vanilla definitions that nothing in the
#     mod uses
