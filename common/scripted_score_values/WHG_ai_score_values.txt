# WHG_ai_score_values.txt: scripted score values
# Subject: weights for AI choices and random picks: who makes a good soldier,
# recruit, target or heir
#
# A scripted score value is a named list of weight modifiers, used in
# ai_chance, ai_will_do, random_list and score_value blocks as "name = yes";
# its factors multiply the weight it is used in. Names are global across the
# folder and must be unique; the load order of files does not matter.
#
# Each entry lists the files that use it ("Used by"). Sections:
#   Shared: used by three or more files (8)
#   Used by WHG_warrior_society_events (8)
#   Other helpers used by one or two files (16)
###############################################################################
