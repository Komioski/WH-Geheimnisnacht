# 00_scripted_triggers.txt (vanilla name: index only)
#
# This file keeps the name of vanilla's 00_scripted_triggers.txt so that it
# replaces it: common/scripted_triggers has no replace_path, so every vanilla
# file without a mod file of the same name would still load. The other vanilla-
# name files here (00_chinese_portrait_triggers.txt,
# 00_french_portrait_triggers.txt, 00_game_rules.txt,
# 01_scripted_triggers_combat.txt, 02_scripted_triggers_warrior_lodges.txt,
# 03_crusades.txt, 04_scripted_triggers_legendary_bloodlines.txt,
# 05_scripted_triggers_holy_order.txt, 06_africa.txt, 07_determine_exile.txt,
# 08_scripted_triggers_LT.txt) are empty for the same reason. The mod's
# scripted triggers are in the WHG_ files of this folder, one per subject.
#
# Files:
#   WHG_bretonnia_triggers.txt (30): Bretonnia: knights, the Lady, the Grail,
#     tourneys
#   WHG_chaos_triggers.txt (210): Chaos: the four gods and Undivided, cults,
#     daemons, the Doom, mutation, beastmen, skaven, Norsca
#   WHG_character_triggers.txt (391): characters: health, personality,
#     lifestyle, family, love, education, mounts and pets
#   WHG_court_triggers.txt (136): the court: council, offices, intrigue, plots,
#     prison, friends and rivals
#   WHG_dwarf_triggers.txt (87): the Dawi: holds, grudges, engineers,
#     runesmiths, the Elder Council, Chaos Dwarfs
#   WHG_east_triggers.txt (327): the East: Cathay, the Ivory Road, the steppe,
#     off-map powers
#   WHG_elves_triggers.txt (28): the elves: Ulthuan (Asur), Athel Loren
#     (Asrai), Naggaroth (Druchii)
#   WHG_empire_triggers.txt (149): the Empire: Electors, colleges, witch
#     hunters, the cults of Sigmar, Verena and Morr
#   WHG_engine_triggers.txt (21): what the game itself calls: hard-coded
#     interaction and crusade buttons, portrait triggers read by
#     interface/portraits
#   WHG_faith_triggers.txt (156): faith: piety, heresy, saints, holy wars,
#     doctrines, monks, coronations, competitions of the faiths
#   WHG_game_rule_triggers.txt (8): the mod's game rules
#   WHG_greenskin_triggers.txt (1): greenskins and ogres: the Waaagh!, tribes,
#     warbosses
#   WHG_kislev_triggers.txt (63): Kislev: the Ice Queen, Praag, Erengrad, the
#     Bulwark, oblasts and stanitsas
#   WHG_legend_triggers.txt (80): ambitions, deeds of legend, great hunts,
#     artifacts, books and debates
#   WHG_magic_triggers.txt (103): magic: the Winds, the lores, wizards, stars
#     and seers
#   WHG_race_triggers.txt (9): races: racial traits, which faiths and cultures
#     fit which race, races without women
#   WHG_realm_triggers.txt (79): the realm: holdings, provinces, laws, economy,
#     slaves, republics, revolts, wonders, alternate start
#   WHG_sea_triggers.txt (87): the sea: ships, voyages, pirates, the sea
#     societies
#   WHG_society_triggers.txt (113): societies: warrior lodges and warbands, the
#     assassins, bloodlines of the orders, other orders not tied to one race
#   WHG_south_triggers.txt (66): the South and the West: Araby, Lustria,
#     Albion, the Southlands, colonies and ventures
#   WHG_undead_triggers.txt (47): the undead: vampires, necromancers,
#     Mousillon, the Tomb Kings of Nehekhara
#   WHG_vanilla_triggers.txt (93): vanilla definitions that nothing in the mod
#     uses
#   WHG_war_triggers.txt (113): war: battles, armies, mercenaries, raids,
#     duels, crusade wars and the armoury
