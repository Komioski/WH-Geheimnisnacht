# Leadership traits (WHG_leadership_traits.txt)
#
# Commander traits (leader = yes): one per commander in battle. Legendary
# lords, terrain, sea and river, raiders and pirates, warrior lodge rewards and
# the leaders of the northern and eastern peoples.
#
# Traits load from every file in this folder (replace_path), alphabetically,
# and a save stores each trait by its place in that order: adding a trait
# anywhere but at the end of the last file, or removing one, breaks old
# saves. Each trait starts with its name in game ("Hidden" for hidden ones)
# and the files that use it, most uses first.
#
# Sections:
#   Commanders (24)
#   Legendary lords (21)
#   Terrain and battle (11)
#   Sea and river (7)
#   Raiders and pirates (9)
#   Warrior lodges (17)
#   Peoples of the north and east (4)
