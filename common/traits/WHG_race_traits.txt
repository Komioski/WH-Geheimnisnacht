# Race traits (WHG_race_traits.txt)
#
# What a character is (one creature_ trait each), castes, Beastman horns, Amazons, Fimir castes, Ogres and animals.
# The race triggers in WHG_race_triggers.txt read these.
#
# Traits load from every file in this folder (replace_path), alphabetically,
# and a save stores each trait by its place in that order: adding a trait
# anywhere but at the end of the last file, or removing one, breaks old
# saves. Each trait starts with its name in game ("Hidden" for hidden ones)
# and the files that use it, most uses first.
#
# Sections:
#   Creatures and daemons (36)
#   Castes (3)
#   Beastman horns and looks (6)
#   Amazons (4)
#   The fey (1)
#   Fimir castes (5)
#   Ogre Kingdoms (4)
#   Animals (1)

##############################################################################
# Creatures and daemons (one per character: what they are)
##############################################################################
