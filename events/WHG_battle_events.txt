#   warrior lodges and berserkers get their own outcomes

# The Holy Fury battle tombola. While a commander fights, battle.1 rolls one

# commander, a rescue, new commander traits, a nickname, a skull, a rival or
# a friend. The scars may come back later as the Wounds Within (battle.26).
# After the fight, battle.100 - 104 tell of heroism, a soldier from the
# ranks, capture and the death of the enemy war leader. The old vanilla
# combat pulse events (242 - 249, 253, 255 - 256, 270 - 273, 96500 - 96503)
# were already remade in the tombola and are gone.
#

# Death on the field               battle.10 - battle.14

# Glory and trophies               battle.60 - battle.73
# Duelist and strategist           battle.80 - battle.82
# Housekeeping                     battle.90 - battle.91
# After the battle                 battle.100 - battle.104
#
# Callers: battle.1 from on_combat_pulse, battle.90 from on_startup and
#   battle.91 from on_death (00_on_actions); battle.26, 31, 32, 33, 35 and 36
#   from the duel effects (01_scripted_effects_duels.txt, wh_scripted_effects);
#   battle.80 - 82 from the duel and battle experience effects.
#   battle.100 and 102 from on_battle_won, battle.103 from on_battle_lost
#   (00_on_actions); battle.104 as a letter from the CB leader-death blocks

		}

					value = 1
					beloved_target_selection_score = yes
				}
				save_event_target_as = my_dear
			}
			set_character_flag = chose_child
		}
		else = {
			any_friend = {

					value = 1
					beloved_target_selection_score = yes
				}
				save_event_target_as = my_dear
			}
			set_character_flag = chose_friend
		}
	}
