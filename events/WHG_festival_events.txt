# Part 1: The Great Tribal Festival
# Namespace: festival (was HF.23800 - HF.23911 in HF_tribal_events.txt)
# Faction: Diplomacy & realms
# Serves: the tribal peoples: Norscans and the Chaos hosts, greenskin tribes,
#   ogre tribes, Ungol, Albion and the other free tribes, Amazons, Lizardmen,
#   tribal Druchii
#
# An independent tribal duke or king (decision hold_great_tribal_festival)
# invites the court and vassals, and a hero of the ruler's warband or lodge
# may come too. Guests prepare, then a season of market stalls, seers,
# feuds, friendships and children's mischief; the host picks one contest
# (brawling, drinking, eating, beast-taming, beauty, poetry, song or
# weaving), whose champion is crowned King or Queen of the Fair; at the end
# the offerings are given to the gods in the faith's own rite. Every good
# deed adds to tribal_festival_divine_favor, which decides the piety,
# prosperity and (for the unreformed old faiths) authority the rite brings.
#
# Warhammer rules: the beast to tame follows the host's people (boars for
# orcs, wolves for goblins, cold ones for Lizardmen and Druchii, great cats
# for Amazons, Stonehorns for ogres, war bears for the Ungol, Ropsmann and
# Kislevites, razorgors for beastmen, horses for the rest;
# [GetFestivalBeast]); ogres and the faithful of Nurgle eat for glory
# and are the favourites of any eating contest; the offering is a Chaos
# blood rite, a Waaagh! bonfire, a feast for the Great Maw, a skink star
# reading, a temple procession or an offering to the ancestors.
#
# Interruptions: death and war    festival.1 - festival.6
# Invitations and preparations    festival.10 - festival.17
# The market and the seer         festival.20 - festival.26
# Friendship at the feast         festival.30 - festival.36
# Spite at the feast              festival.40 - festival.47
# Children at the festival        festival.50 - festival.72
# The contest is called           festival.100 - festival.115
# The contest                     festival.120
# Champions                       festival.130 - festival.155
# The offering                    festival.160 - festival.161
#
# Callers: decisions/HF_realm_decisions.txt (hold_great_tribal_festival)
#   fires festival.10 and the 300-day clean-up festival.1; 00_on_actions
#   fires festival.2 (on_death) and festival.4 (on_war_started); the flavour
#   lists, contest picks and the effects named below live in
#   common/scripted_effects/05_scripted_effects_competitions.txt.
# Saved: flags flag_holding_great_tribal_festival, flag_host_holding_*,
#   flag_tribal_festival_*_contender, flag_child_race_winner; variable
#   tribal_festival_divine_favor; persistent event target warband_guest (the
#   lodge hero, named in loc as festival_hero); opinion
#   opinion_great_tribal_festival_guest; modifier
#   held_great_tribal_festival_cooldown; all cleared by
#   clean_up_great_tribal_festival_flags_effect.
# Rewards: the beast-taming champion may keep a beast as a mount (festival
#   .139, 15%, once per lifetime, only with no mount; an existing mount
#   artifact by people: boar, wolf, cold one, great cat, Stonehorn, war
#   bear, steppe courser or courser; festival_tamed_mount_effect, flag
#   festival_tamed_mount).
# Triggers: common/scripted_triggers/wh_festival_triggers.txt
# Loc: localisation/00_WHG_festival_events.csv
###############################################################################

# festival.1 Clean-up
# Hidden. Clears the festival from the host and every guest. A safety net 300
# days after the decision, in case the chain broke.
# Scope: ROOT is the host. Fired from the decision and festival.11, 13.
character_event = {
	id = festival.1
	hide_window = yes

	is_triggered_only = yes

	immediate = {
		clean_up_great_tribal_festival_flags_effect = yes
		any_vassal = {
			limit = {
				has_opinion_modifier = { who = ROOT modifier = opinion_great_tribal_festival_guest }
			}
			clean_up_great_tribal_festival_flags_effect = yes
		}
	}
}

# festival.10 Invitations
# The host sends invitations to courtiers and vassals (festival.11) and,
# half the time, to a hero of the host's warband or lodge (festival.13).
# The host prepares in 20 days (festival.15).
# Scope: ROOT is the host. Fired from hold_great_tribal_festival.

	id = festival.10
	title = EVTTITLEfestival
	desc = EVTDESCfestival10
	picture = GFX_evt_tribal_lands
	border = GFX_event_normal_frame_diplomacy

	is_triggered_only = yes

	immediate = {
		save_event_target_as = great_tribal_festival_host
	}

	option = {
		name = EVTOPTAfestival10
		custom_tooltip = { text = EVTTOOLTIPfestival10_a }
		hidden_tooltip = {
			any_courtier_or_vassal = {
				limit = {
					age = 8 #Children get their own events.
					NOR = {
						prisoner = yes
						has_character_flag = do_not_disturb
						has_character_modifier = holding_large_feast
						has_any_opinion_modifier = opinion_coronation_guest
						has_any_opinion_modifier = opinion_great_tribal_festival_guest
						trait = incapable
						is_inaccessible_trigger = yes
					}
				}
				letter_event = { id = festival.11 }
			}
			if = {
				limit = {
					OR = {
						is_member_of_any_warband_trigger = yes
						is_member_of_any_warrior_lodge_trigger = yes
					}
				}
				random_society_member = { #Possible Hero guest.
					limit = {
						same_society_as = ROOT
						society_rank = 4
						ai = yes
						NOR = {
							prisoner = yes
							character = ROOT
							liege = { character = ROOT }
							top_liege = { character = ROOT }
							has_character_flag = do_not_disturb
							has_character_modifier = holding_large_feast
							has_any_opinion_modifier = opinion_coronation_guest
							has_any_opinion_modifier = opinion_great_tribal_festival_guest
							trait = incapable
							is_inaccessible_trigger = yes
						}
					}
					random = {
						chance = 50
						modifier = { factor = 1.25 ROOT = { real_tier = KING } }
						modifier = { factor = 1.5 ROOT = { real_tier = EMPEROR } }
						modifier = { factor = 1.5 ROOT = { prestige = 500 } }
						letter_event = { id = festival.13 }
					}
				}
			}
			character_event = { id = festival.15 days = 20 } #Preparation event for host.
		}
	}

# Part 3: The Summer Fair (namespace fair)
# Namespace: fair (was 74000 - 74050, 4105 and 4170 in summer_fair_events.txt;
#   fair.N = old id minus 73900, the puppets fair.160, the bear fair.170)
# Faction: Generic
# Serves: rulers of the Old World and the Moot
#
# Between April and June a ruler of an Old World or halfling faith may hold
# a Summer Fair (decision summer_fair in minor_decisions.txt). For sixty days
# the town fills with monkeys, archers, a jester, mummers, strolling
# players, jugglers, fortune-tellers, a flagellant crying the End Times,
# thieving peddlers, a puppet show that mocks the host and a dancing bear;
# each turns up at most once per fair, a few days apart.
#
#   fair.100 - 145   The fair's entertainments and troubles
#   fair.147         The fair is over
#   fair.150         The fair begins
#   fair.160, 170    The puppet show and the dancing bear
#
# Fired from: the decision summer_fair (fair.150 at once, fair.147 after 60
#   days). The rest are MTTH events behind the summer_fair_begin flag.
# Fixed: the mod had no text for any of these events; the vanilla texts are
#   here, with the Church's gleemen and the errant monk now the temples'
#   and a flagellant of Sigmar. The MTTH events were checked on every ruler
#   in the world; they now need the fair's own flag first. The bear wrestler
#   is checked with is_woman_trigger.
# Dropped: the commented-out "Jumping Jews of Jerusalem" (74035).
# Saved: character modifier holding_summer_fair; flags summer_fair_begin,
#   fair_event_happened, fair_event_<id>, recent_summer_fair, do_not_disturb.
