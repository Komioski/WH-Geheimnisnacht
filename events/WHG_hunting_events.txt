###############################################################################
# Way of Life: the hunting focus
# Namespace: hunting (was WoL.5000 - WoL.5291 in wol_hunting_events.txt)
# Faction: Generic
#
# The white beast: peasants whisper of a white beast in the wilds of the
# realm, a white hart in the Old World and Athel Loren, a white bear in the
# north, a white tiger in the hot south and a white lion in Ulthuan, Araby
# and the badlands. The hunter sets out after it again and again until the
# beast is caught. To a follower of Taal or Kurnous the white hart is the
# god's own beast, and so is the white bear to a Kislevite who prays to
# Ursun: they should let it run. To an Asur of Chrace the white lion is the
# oldest rite of the hunt, and its pelt is worn with pride.
#
# The hound: a friend, spouse, lover or courtier gives the hunter a puppy.
# It grows into a good hound (or a vicious one), cheers its master, charms
# the court or mauls it, is trained, and dies one day.
#
# The white beast                      hunting.1 - hunting.7
# The hunt                             hunting.10 - hunting.23
# The hound                            hunting.30 - hunting.51
# Part 4: The grand hunt               hunting.100 - hunting.199
#   (the hold_grand_hunt decision: a stag, a boar, a bear, the hounds, a
#   plot in the woods, a courtier's kill, the deer park; was 36000 - 36999
#   and 4075 in the vanilla hunting_events.txt)
# Part 5: The great cat hunt           tigerhunt.1 - tigerhunt.45
#   (hold_tiger_hunt in Araby and Lustria; was RoI.2000 - 2999)
# Part 6: The monster hunt             huntdown.1 - huntdown.46
#   (plot_hunt_character: hunting a Daemon Prince, a vampire, a forest
#   spirit or a Slann in its lair; was S_hunting_monsters_events.txt)
#
# Fired from: on_focus_pulse in 00_on_actions.txt (hunting.1, .30, .40, .41,
#   .42, .44, .45). hunting.6 is a scene of the grand hunt (hunting.101).
#   hunting.50 is also scheduled by the pet events, the offmap
#   effects and the legendary bloodline effects; hunting.51 by the Cathayan
#   envoy's snake (ivory.9). Shared triggers and effects are in
#   WHG_focus_triggers.txt and WHG_focus_effects.txt; the grand hunt's in
#   WHG_grand_hunt_triggers.txt and WHG_grand_hunt_effects.txt.
###############################################################################

# hunting.3 Router: news of the white beast
# Waits while the hunter is busy, then finds a realm county within 500 of
# the capital where the beast was seen (hunting.5). A hunter who left the
# hunting focus gives up the chase.
# Scope: the hunter.
character_event = {
	id = hunting.3
	hide_window = yes
	is_triggered_only = yes # hunting.2, hunting.7, hunting_beast_escapes_effect

	immediate = {
		if = {
			limit = { NOT = { has_focus = focus_hunting } }
			hunting_legend_abandoned_effect = yes
		}
		else_if = {
			limit = {
				OR = {
					has_regent = yes
					in_command = yes
					prisoner = yes
					trait = pregnant
					has_character_flag = do_not_disturb
				}
			}
			repeat_event = { id = hunting.3 days = 30 }
		}
		else = {
			capital_scope = {
				ROOT = {
					random_realm_province = {
						limit = { NOT = { distance = { where = PREVPREV distance = 500 } } }
						save_event_target_as = hunting_beast_county
					}
				}
			}
			character_event = { id = hunting.5 }
		}
	}
}

# hunting.11 Router: how the hunt goes
# The beast is caught rarely; hunters, the persistent, the skilled and those
# with a good hound catch it more often. The cottage outcomes need a race
# with women. Vampires, Tomb Kings and daemons do not tire, hunger or meet
# strangers in cottages: the wild flees them instead (hunting.23).
# Scope: the hunter.
character_event = {
	id = hunting.11
	hide_window = yes
	is_triggered_only = yes # hunting.10

	immediate = {
		random_list = {
			2 = { # The beast is cornered
				modifier = { factor = 2 trait = hunter }
				modifier = { factor = 2 has_character_flag = failed_epic_hunt }
				modifier = { factor = 1.5 martial = 15 }
				modifier = { factor = 1.5 has_character_modifier = pet_hunting_dog }
				character_event = { id = hunting.12 }
			}
			10 = { # So close, across a gorge
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.13 }
			}
			10 = { # A rival hunter
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.14 }
			}
			10 = { # Lost, and miserable
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.15 }
			}
			10 = { # Lost, and glad of it
				modifier = { factor = 0 focus_unliving_trigger = yes }
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.16 }
			}
			30 = { # Nothing
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.17 }
			}
			40 = { # The beasts flee the unliving
				trigger = { focus_unliving_trigger = yes }
				character_event = { id = hunting.23 }
			}
			10 = { # The crone in the cottage
				modifier = { factor = 0 is_no_females_race = yes }
				modifier = { factor = 0 focus_unliving_trigger = yes }
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.18 }
			}
			10 = { # The stranger in the cottage
				modifier = { factor = 0 is_no_females_race = yes }
				modifier = { factor = 0 focus_unliving_trigger = yes }
				modifier = { factor = 0.25 trait = celibate }
				set_character_flag = failed_epic_hunt
				character_event = { id = hunting.21 }
			}
		}
	}
}

# hunting.12 The beast is cornered
# Kill it or spare it. The faithful of Taal, Kurnous and Ursun lose piety
# for the kill and gain it for mercy; an Asur of Chrace gains piety for the
# lion's death and loses some for sparing it. A kill may rarely leave a trophy (lion cloak for the Asur,
# antlers for the hart, a pelt for the rest), and mercy may rarely bring the
# beast home as a mount (hart, bear or tiger). Each once a lifetime.
# Scope: the hunter.
character_event = {
	id = hunting.12
	desc = {
		trigger = { has_character_flag = white_stag hunting_taal_hart_trigger = no }
		text = EVTDESChunting12
	}
	desc = {
		trigger = { has_character_flag = white_bear hunting_ursun_bear_trigger = no }
		text = EVTDESChunting12b
	}
	desc = { trigger = { has_character_flag = white_tiger } text = EVTDESChunting12c }
	desc = {
		trigger = { has_character_flag = white_lion hunting_chrace_lion_trigger = no }
		text = EVTDESChunting12d
	}
	desc = { trigger = { hunting_taal_hart_trigger = yes } text = EVTDESChunting12e }
	desc = { trigger = { hunting_ursun_bear_trigger = yes } text = EVTDESChunting12f }
	desc = { trigger = { hunting_chrace_lion_trigger = yes } text = EVTDESChunting12g }
	picture = GFX_evt_mysterious_forest
	border = GFX_event_normal_frame_war

	is_triggered_only = yes # hunting.11

	option = { # The kill
		name = EVTOPTAhunting12
		prestige = 200
		if = { limit = { hunting_sacred_beast_trigger = yes } piety = -150 }
		if = { limit = { hunting_chrace_lion_trigger = yes } piety = 100 }
		if = { limit = { NOT = { lifestyle_traits = 1 } } add_trait = hunter }
		if = { limit = { ai = no } set_character_flag = achievement_great_hunter }
		if = {
			limit = {
				NOT = { has_character_flag = hunt_trophy_given }
				NOT = { has_artifact = white_hart_antlers }
				NOT = { has_artifact = white_beast_pelt }
				NOT = { has_artifact = asur_artifact_lion_cloak }
			}
			random = {
				chance = 35
				set_character_flag = hunt_trophy_given
				if = {
					limit = { hunting_chrace_lion_trigger = yes }
					add_artifact = asur_artifact_lion_cloak
				}
				else_if = {
					limit = { has_character_flag = white_stag }
					add_artifact = white_hart_antlers
				}
				else = { add_artifact = white_beast_pelt }
			}
		}
		hunting_legend_won_effect = yes
		ai_chance = {
			factor = 1
			modifier = { factor = 0.05 hunting_sacred_beast_trigger = yes }
			modifier = { factor = 5 hunting_chrace_lion_trigger = yes }
			modifier = { factor = 2 trait = cruel }
			modifier = { factor = 2 trait = proud }
			modifier = { factor = 0.5 trait = kind }
		}
	}
	option = { # Mercy
		name = EVTOPTBhunting12
		prestige = 200
		if = { limit = { hunting_sacred_beast_trigger = yes } piety = 100 }
		if = { limit = { hunting_chrace_lion_trigger = yes } piety = -50 }
		if = {
			limit = {
				NOT = { has_character_flag = hunt_mount_given }
				NOT = { has_character_flag = white_lion }
				NOT = { has_artifact = asrai_stag }
				NOT = { has_artifact = war_bear_mount }
				NOT = { has_artifact = amazon_tiger }
			}
			random = {
				chance = 20
				modifier = { factor = 2 hunting_sacred_beast_trigger = yes }
				set_character_flag = hunt_mount_given
				set_character_flag = has_mount
				if = { limit = { has_character_flag = white_stag } add_artifact = asrai_stag }
				else_if = {
					limit = { has_character_flag = white_bear }
					add_artifact = war_bear_mount
				}
				else = { add_artifact = amazon_tiger }
				custom_tooltip = { text = hunting_beast_follows_tt }
			}
		}
		hunting_legend_won_effect = yes
		ai_chance = {
			factor = 1
			modifier = { factor = 10 hunting_sacred_beast_trigger = yes }
			modifier = { factor = 0.1 hunting_chrace_lion_trigger = yes }
			modifier = { factor = 2 trait = kind }
			modifier = { factor = 0.5 trait = cruel }
		}
	}
}

# Part 5: The great cat hunt (namespace tigerhunt)
# Namespace: tigerhunt (was RoI.2000 - RoI.2999 in roi_hunting_events.txt)
# Faction: Generic
# Serves: rulers of Araby and the colonies of Lustria
#
# A ruler whose capital lies in Araby or Lustria holds a tiger hunt
# (hold_tiger_hunt, Rajas of India) and invites the vassals. Around the
# camp fires the hunters drink, quarrel and gamble; in the jungle and the
# scrub a tiger may spring on the party, or the scouts flush one out for
# the host to spear. A slain tiger is good luck for the realm.
#
#   tigerhunt.1 - 3     Invitations
#   tigerhunt.10 - 15   The hunt begins and ends; flags cleared
#   tigerhunt.20 - 27   Around the camp: drink, friends, enemies, cards
#   tigerhunt.30 - 33   A tiger springs on the party
#   tigerhunt.40 - 45   The tiger is found: spear it yourself, or let the
#                       soldiers do it
#
# Fixed: a tiger killed by a guest did not count, so the host's hunt
#   "failed" (tigerhunt.12 now counts any hunter), and a failed hunt left
#   the guests' killed_tiger flag behind for the next hunt.
# New: a host who spears the tiger may, rarely, keep its pelt
#   (great_cat_pelt in 40_artifacts_hunting.txt: 15%, once a lifetime,
#   never beside another trophy).
# Fired from: decisions/minor_decisions.txt (hold_tiger_hunt: 1).
# Saved: character flags holding_tiger_hunt, hunting_tigers, killed_tiger,
#   do_not_disturb (all cleared at the end); character modifiers hunt_timer,
#   good_hunt.
# Loc: localisation/00_WHG_hunting_events.csv
###############################################################################

namespace = tigerhunt

# tigerhunt.1 Invite vassals to hunt
character_event = {
	id = tigerhunt.1
	desc = EVTDESCtigerhunt1
	picture = GFX_evt_throne_room

	is_triggered_only = yes

	option = {
		name = EVTOPTAtigerhunt1
		any_vassal = {
			limit = {
				is_adult = yes
				NOR = {
					war = yes
					in_command = yes
					prisoner = yes
					trait = incapable
					has_character_flag = do_not_disturb
				}
			}
			letter_event = { id = tigerhunt.2 tooltip = EVTTOOLTIPtigerhunt1 }
		}
		hidden_tooltip = { character_event = { id = tigerhunt.11 days = 12 } } # Hunt begins
		hidden_tooltip = { character_event = { id = tigerhunt.12 days = 42 } } # Hunt ends
	}
}

	id = tigerhunt.2
	desc = EVTDESCtigerhunt2

	is_triggered_only = yes

	trigger = {
		NOT = { is_inaccessible_trigger = yes }
	}

	option = {
		name = EVTOPTAtigerhunt2 # Go
		ai_chance = {
			factor = 2
			modifier = { factor = 5 has_focus = focus_hunting }
			modifier = { factor = 0.1 is_inaccessible_trigger = yes }
			modifier = { factor = 2 opinion = { who = from value = -30 } }
			modifier = { factor = 5 opinion = { who = from value = -15 } }
			modifier = { factor = 5 opinion = { who = from value = 0 } }
		}
		set_character_flag = do_not_disturb

		hidden_tooltip = { character_event = { id = tigerhunt.10 days = 12 } } # Hidden - arrives to hunt
		hidden_tooltip = { character_event = { id = tigerhunt.15 days = 43 } } # Safety event for clearing all flags
		custom_tooltip = { text = EVTTOOLTIPtigerhunt2 }
	}
	option = {
		name = EVTOPTBtigerhunt2 # Don't go
		ai_chance = {
			factor = 1
			modifier = {
				factor = 0
				opinion = { who = from value = 25 }
				NOT = { is_inaccessible_trigger = yes }
			}
		}
		FROM = { letter_event = { id = tigerhunt.3 days = 3 tooltip = EVTTOOLTIPtigerhunt2 } }
	}
}

# Part 6: The monster hunt (namespace huntdown)
# Namespace: huntdown (was huntdown.1 - huntdown.9999 in
#   S_hunting_monsters_events.txt; renumbered below 100)
# Faction: Generic
# Serves: witch hunters, vampire hunters, Slayers, Grail knights, zealots,
#   madmen and orcs who want a proper fight
#
# A plotter who has formed the plot to hunt a monster (plot_hunt_character:
# a Daemon Prince, a forest spirit, a Slann, a vampire) sets out after it,
# or sends the marshal, a witch hunter or an elven mage. The hunters cast
# protective spells, wait for dawn, check for traps or just go in; the
# monster may discover them, blast them with magic, set its thralls on them
# or face them at last in a deadly duel. A slain monster wins its slayer a
# nickname, prestige and (rarely) a trophy for the hall.
#
#   The hunter makes ready (yearly)    huntdown.10
#   The plot chosen, the hunter sent   huntdown.1 - 5
#   The approach                       huntdown.20
#   Discovered                         huntdown.21 - 29
#   The sanctum                        huntdown.30 - 36
#   The plotter hears                  huntdown.29 (failure), 39 (success)
#   The final duel                     huntdown.40 - 46
#
# Callers: plot_hunt_character (common/objectives/wh_plots.txt) starts the
#   yearly huntdown.10 when the plot is formed; huntdown.42 calls
#   cultofmorr.142 for a Morrite vampire hunt.
# Saved: flags huntdown_in_motion (a hunt is under way), huntdown_loop (the
#   yearly check runs), took_monster_hunt_trophy, attacking_at_dawn,
#   vampire_hiding_dark; opinion opinion_monsterhunting_beacon; event
#   targets antimonster_plotter, hunted_monster.
# Fixed: the old start was a twelve-year MTTH on every character; the
#   breaks after antideath_effect skipped the plotter's notice and left him
#   stuck; a sent courtier could only accept if he had a marshal of his own;
#   "wait" and a refusing courtier left the plotter's flag set for good; a
#   plotter who failed was never freed to try again; Undivided Daemon Princes
#   used the Khorne texts; huntdown.43 (the dead do not stay dead) had no
#   caller.
###############################################################################
