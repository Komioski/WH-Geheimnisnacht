###############################################################################
# Realm events
# Namespace: realm (was HFP.40000 - HFP.40038, HFP.24120, HFP.99999 in
#   HFP_realm_events)
# Faction: Diplomacy & realms
# Serves: the Empire, the cult of Sigmar, the merchant republics, the
#   Border Princes, the conquerors of Araby
#
# The vanilla realm-forming news (vanilla decisions/HFP_realm_decisions),
# moved to the mod's own analogues:
# - Papal States lost -> the Grand Theogonist cast out (1-2): when he loses
#   the last of the temple's lands in a war, every Sigmarite ruler hears of
#   it, at most once a decade;
# - Venice, Genoa, Pisa, Amalfi -> any merchant republic that takes a crown
#   (10);
# - Switzerland, Antioch, Cyprus -> the Border Princes refound the Eagle
#   and Northern Border Confederacies, Khypria and Myrmidens (20-21);
# - the Eastern Marches -> the East March: the Elector of Ostermark becomes
#   Warden of the eastern frontier (30-32);
# - the Archduchy of Austria -> a favoured duke of Ostland is raised to
#   Grand Prince by the Emperor (35-36);
# - Outremer -> a ruler of the Old World faiths or of the Lady who takes
#   the crown of Araby founds the Blood of the Conqueror of Araby (40-41);
# - the papal guards -> the Knights of the Griffon raised again (60);
# - the Slavic union -> the Union of the Old Peoples: a free Ungol or
#   Ropsmann king who rules many lands of both peoples unites them against
#   the Gospodar tsars, and their lands hold out against the Kislevite
#   melting pot (70-71). Very rare, once per game.
# The HRE stem duchies are the de jure realms of Drakwald and Solland
# (wh_empire_decisions, realm.100-103), which the Emperor may now restore too.
#
# The Grand Theogonist cast out   realm.1 - realm.2
# Merchant crowns                 realm.10
# The Border Princes refounded    realm.20 - realm.21
# The East March                  realm.30 - realm.32
# The Grand Prince of Ostland     realm.35 - realm.36
# The fall of Araby               realm.40 - realm.41
# The Griffons return             realm.60
# The Union of the Old Peoples    realm.70 - realm.71
# Elective commanders            realm.80 - realm.83 (was HFP.20803 - HFP.20806
#   in HFP_random_flavor_events): the electors of Tilea, Estalia and the
#   Eternal Empire remember the generals a ruler sacks and appoints
# The Saoshyant of Ormazd          realm.90 - realm.92 (was TOG.6000 - 6003 in
#   the vanilla oldgods_zoroastrian_events, never copied in): the Emperor
#   of Araby who holds all Araby for Ormazd is hailed as the saviour
# Free of a suzerain              realm.95 - realm.96 (was JD.60015 - 60016 in
#   jd_chinese_diplomacy_events): a player tributary hears that the
#   suzerain's death ended the tribute
# The lost Elector provinces      realm.100 - realm.103 (was ee.1 - ee.4 in
#   ee_events.txt): Drakwald and Solland raised again
#
# Saved: global flags east_march_proclaimed, grand_prince_ostland_raised,
#   araby_conquered_by_old_world, old_peoples_united; title flags gt_cast_out
#   (k_cult_of_sigmar), east_march (k_ostermark); character flags
#   realm_refound_<eagle|northern|khypria|myrmidens>; character modifier
#   warden_of_the_east_march; event targets grand_theogonist,
#   griffon_grandmaster, restorer_old_primary; unit earmark old_peoples_host;
#   opinion opinion_elector_lands_taken (wh_empire_opinions).
#
# Callers:
#   common/scripted_effects/00_scripted_effects.txt (landless_pope_effect:
#     1), run by the CBs when a war is lost;
#   common/on_actions/00_on_actions.txt: on_death (95), on_create_title
#     (10, 40),
#     on_new_holder, on_new_holder_inheritance, on_new_holder_usurpation
#     (32);
#   decisions/WHG_realm_decisions.txt (realm_refound_*: 20,
#     realm_east_march: 30, realm_grand_prince_ostland: 35,
#     realm_refound_griffons: 60, realm_old_peoples_union: 70);
#   decisions/wh_empire_decisions.txt (de_jure_realm_drakwald: 100-101,
#     de_jure_realm_solland: 102-103).
#
# Already covered elsewhere: the Hansa is the Marienburg League
# (mleague.10 - 21 in WHG_republic_events), the HRE electors are the
# Elector Counts, the crusader orders are the mod's own holy orders. Not carried over: Byzantium.
#
# Also in this file (each part keeps its own header and namespace):
#   Part 2: County prosperity (namespace prosper)
#   Part 3: The liege steps in between vassals (namespace liege)
#   Part 4: Landfall in the New World (namespace landfall)
#   Part 5: News from the East (namespace eastnews)
#   Part 6: The Red Cord (namespace murdercult)
#   Part 7: Triumphs (namespace triumph)
#   Part 8: Lost lands reclaimed (namespace lostlands)
#   Part 9: Brief pacts (namespace pact)
#   Part 10: Civil war (namespace civilwar)
#   Part 11: Debt (namespace debt)
#   Part 12: Elective leagues (namespace league)
#   Part 13: Burghers, priests and lords (namespace lordship)
#   Part 14: Vassal requests (namespace vassalreq)
###############################################################################

namespace = realm

###############################################################################
# The Grand Theogonist cast out
###############################################################################

# realm.1 The temple's last lands are lost (hidden)
# Scope: the Grand Theogonist, who holds no land and whose realm holds none.
character_event = {
	id = realm.1
	hide_window = yes

	is_triggered_only = yes

	trigger = {
		has_landed_title = k_cult_of_sigmar
		k_cult_of_sigmar = { NOT = { had_title_flag = { flag = gt_cast_out days = 3650 } } }
	}

	immediate = {
		k_cult_of_sigmar = { clr_title_flag = gt_cast_out set_title_flag = gt_cast_out }
		save_event_target_as = grand_theogonist
		narrative_event = { id = realm.2 }
		any_playable_ruler = {
			limit = { religion = sigmarite NOT = { character = ROOT } }
			narrative_event = { id = realm.2 }
		}
	}
}

# realm.2 The Grand Theogonist cast out (news)
# Scope: a Sigmarite ruler, or the Grand Theogonist.
narrative_event = {
	id = realm.2
	title = EVTTITLErealm2
	desc = { trigger = { character = event_target:grand_theogonist } text = EVTDESCrealm2_gt }
	desc = {
		trigger = { NOT = { character = event_target:grand_theogonist } }
		text = EVTDESCrealm2
	}
	picture = GFX_evt_cathedral
	border = GFX_event_narrative_frame_religion

	is_triggered_only = yes

	option = { #The Grand Theogonist
		name = EVTOPTArealm2
		trigger = { character = event_target:grand_theogonist }
		piety = -100
	}
	option = { #A zealot
		name = EVTOPTBrealm2
		trigger = { NOT = { character = event_target:grand_theogonist } trait = zealous }
		piety = 25
	}
	option = { #Anyone else
		name = EVTOPTCrealm2
		trigger = { NOT = { character = event_target:grand_theogonist } NOT = { trait = zealous } }
	}
}

# realm.32 The wardenship passes with Ostermark (hidden)
# From on_new_holder, on_new_holder_inheritance, on_new_holder_usurpation.
# Scope: the new holder; FROM is the title; FROMFROM the old holder.
character_event = {
	id = realm.32
	hide_window = yes

	is_triggered_only = yes
	only_rulers = yes

	trigger = {
		has_global_flag = east_march_proclaimed
		FROM = { title = k_ostermark has_title_flag = east_march }
	}

	immediate = {
		add_character_modifier = { modifier = warden_of_the_east_march duration = -1 }
		FROMFROM = {
			if = {
				limit = { NOT = { has_landed_title = k_ostermark } }
				remove_character_modifier = warden_of_the_east_march
			}
		}
	}
}

# The Union of the Old Peoples
###############################################################################

# realm.70 The old peoples unite
# From realm_old_peoples_union (decisions/WHG_realm_decisions.txt). The
# Tsar and the other rulers of Kislev hear of it (realm.71). The founder
# may raise a steppe host (once per game, as the union is).
# Scope: the founder (Ungol or Ropsmann).
narrative_event = {
	id = realm.70
	title = EVTTITLErealm70
	desc = { trigger = { culture = ropsmann } text = EVTDESCrealm70_ropsmann }
	desc = { trigger = { NOT = { culture = ropsmann } } text = EVTDESCrealm70_ungol }
	picture = GFX_evt_council
	border = GFX_event_narrative_frame_diplomacy

	is_triggered_only = yes

	immediate = {
		if = { # Union of the Old Peoples (WHG_ambitions)
			limit = { has_ambition = obj_union_of_the_old_peoples }
			set_character_flag = amb_old_peoples_united
		}
		any_playable_ruler = {
			limit = {
				NOT = { character = ROOT }
				OR = {
					has_landed_title = e_kislev
					any_realm_province = { region = world_old_world_kislev }
				}
			}
			narrative_event = { id = realm.71 }
		}
	}

	# Raise the host of the old peoples.
	option = {
		name = EVTOPTArealm70
		capital_scope = {
			spawn_unit = {
				province = PREV
				owner = ROOT
				troops = { horse_archers = { 300 300 } light_cavalry = { 150 150 } }
				earmark = old_peoples_host
				maintenance_multiplier = 0.5
			}
		}
		ai_chance = { factor = 2 }
	}

	# Keep the old ways at home: the khans and stanitsas rally to the union.
	option = {
		name = EVTOPTBrealm70
		prestige = 300
		any_vassal = {
			limit = { OR = { culture = ungol culture = ropsmann } }
			opinion = { modifier = opinion_happy who = ROOT years = 10 }
		}
		ai_chance = { factor = 1 }
	}
}

# From realm_become_saoshyant for the Saoshyant's children, and on_birth for
# every later descendant; passes down the line.
# Scope: the child.

	id = realm.91
	hide_window = yes

	is_triggered_only = yes

	has_global_flag = saoshyant_appears

	trigger = {
		NOT = { trait = saoshyant_descendant }
		OR = {
			mother = { OR = { trait = saoshyant trait = saoshyant_descendant } }

		}
	}

	immediate = {
		add_trait = saoshyant_descendant
		any_child = { character_event = { id = realm.91 } }
	}

###############################################################################
# Part 2: County prosperity (namespace prosper)
# Faction: Generic
# Serves: any playable ruler of a settled realm; the Elder Races prosper
# slowly.
#
# Every year a county at peace may rise one prosperity level; sieges,
# looting and epidemics take it away. A thriving crown focus county rolls
# boom events.
#   prosper.1-4      The yearly roll, and losing prosperity
#   prosper.5-22     Crown focus booms: Strigany caravans, new land, workers,
#                    a monument, a harbour, scholars, a library, a centre of
#                    worship, loggers, a mine, a minority, regimental grounds
#   prosper.23-25    Flag cleanup for old depopulation
#   prosper.30-35    A councillor suggests roads, shrines, outposts,
#                    messengers, harvest festivals, or a visit
#
# Callers: on_yearly_pulse (1, 30-35 random list), on_siege_over_winner (3,
# 14), on_loot_settlement (21), on_new_holder* (16), the epidemics in
# common/disease (4).
# Was events/rip_prosperity_events.txt (RIP.11700-11724 = prosper.1-25) and
# RIP.4300-4305 in rip_flavor_events.txt (prosper.30-35).
###############################################################################

namespace = prosper

###############################################################################
# The yearly roll (prosper.1-4, 13, 16, 21)
###############################################################################

# prosper.1 Yearly prosperity roll
# Hidden. Rolls prosperity for every settled demesne county (and places of
# power) not depopulated.
# Scope: ROOT is a playable ruler. Fired by on_yearly_pulse.
character_event = {
	id = prosper.1

	hide_window = yes

	is_triggered_only = yes

	only_playable = yes

	immediate = {
		any_realm_province = {
			limit = {
				OR = {
					any_province_holding = { #empty provinces (including provinces with ONLY a temple) do not prosper
						OR = { holding_type = city holding_type = castle holding_type = tribal }
					}
					OR = {
						has_province_modifier = active_place_of_power_man
						has_province_modifier = active_place_of_power_elf
						has_province_modifier = active_place_of_power_wood
						has_province_modifier = corrupt_place_of_power_man
						has_province_modifier = corrupt_place_of_power_elf
						has_province_modifier = corrupt_place_of_power_wood
					}
				}
				owner = { character = ROOT }
				NOR = {
					has_province_modifier = depopulated_1
					has_province_modifier = depopulated_2
					has_province_modifier = depopulated_3
				}
			}
			province_event = { id = prosper.2 }
		}
	}
}

# prosper.2 Prosperity grows or falls
# Hidden. Chance (stewardship, bloodlines, trade posts, bad modifiers, the
# slow-growing Elder Races) to rise to the next prosperity level; war, sieges
# and disease stop it.
# Scope: ROOT is the county. Fired by prosper.1.
province_event = {
	id = prosper.2

	hide_window = yes

	is_triggered_only = yes

	option = {
		random = {
			chance = 50 #50/50 base chance to increase
			modifier = {
				factor = 1.5
				owner = {
					any_owned_bloodline = { has_bloodline_flag = bloodline_peace_prosperity }
				}
			}
			modifier = {
				factor = 1.25
				owner = { has_character_modifier = african_adulthood_rites_1 }
			}
			modifier = { factor = 1.2 owner = { has_province_modifier = southland_heavy_rain } }
			modifier = {
				factor = 1.5 #over 16 stewardship you have a 75% chance
				owner = { stewardship = 16 }
			}
			modifier = {
				factor = 1.5 #over 20 stewardship you increase 100%
				owner = { stewardship = 20 }
			}
			modifier = {
				factor = 1.2 #having trade posts increases the chance
				has_trade_post = yes
			}
			modifier = {
				factor = 0.9 #having under 10 stewardship slightly reduces the chance
				owner = { NOT = { stewardship = 10 } }
			}
			modifier = {
				factor = 0.8 #having under 4 stewardship significantly reduces the chance
				owner = { NOT = { stewardship = 4 } }
			}
			modifier = {
				factor = 0.9 #not being independent slightly reduces the chance
				owner = { NOT = { independent = yes } }
			}
			modifier = {
				factor = 0.6 #tribes prosper slower
				AND = {
					owner = { is_tribal = yes }
					any_province_holding = { holding_type = tribal }
				}
			}
			modifier = {
				factor = 0.5 #bad province modifiers decrease chance
				OR = {
					has_province_modifier = incompetent_rule
					has_province_modifier = thieves_guild
					has_province_modifier = smugglers_ring
					has_province_modifier = highway_robber_band
					has_province_modifier = heretic_stronghold
					has_province_modifier = religious_tension
					has_province_modifier = temple_corruption
					has_province_modifier = local_death_cult
					has_province_modifier = extra_tax
					has_province_modifier = southland_drought_risk
					has_province_modifier = southland_drought
				}
			}
			modifier = {
				factor = 0.4 #The Ancient Races develop much slower
				OR = {
					culture_group = asrai_group
					culture_group = asur_group
					culture_group = druchii_group
					culture_group = dwarf_group
					culture_group = dwarf_chaos_group
					culture_group = lizardman_group
				}
			}
			modifier = {
				factor = 0.2 #The Barbaric races develop even slowly
				OR = {
					culture_group = beastman_group
					culture_group = goblin_group
					culture_group = ogre_group
					culture_group = orc_group
				}
			}
			modifier = {
				factor = 0.1 #Nehekharans develop extremely slowly ( BECAUSE THEY'RE DEAD )
				culture_group = nehekharan_group
			}
			modifier = {
				factor = 0.7 #slightly lower chance if helping in a war
				owner = {
					war = yes
					NOR = { is_primary_war_defender = yes is_primary_war_attacker = yes }
				}
			}
			modifier = {
				factor = 0.5 #low chance if defending in a war
				owner = { is_primary_war_defender = yes NOT = { is_primary_war_attacker = yes } }
			}
			modifier = {
				factor = 0.2 #very low chance if attacking in a war
				owner = { is_primary_war_attacker = yes }
			}
			modifier = {
				factor = 0 #no chance if under siege/occupied/diseased
				OR = {
					any_province_holding = { has_siege = yes }
					any_province_holding = { is_occupied = yes }
					has_disease = yes
				}
			}
			#gain depends on terrain type
			trigger_switch = {
				on_trigger = terrain
				city = { change_variable = { which = prosperity_value value = 10 } }
				urban = { change_variable = { which = prosperity_value value = 10 } }
				farmlands = { change_variable = { which = prosperity_value value = 10 } }
				plains = { change_variable = { which = prosperity_value value = 8 } }
				steppe = { change_variable = { which = prosperity_value value = 8 } }
				woods = { change_variable = { which = prosperity_value value = 7 } }
				forest = { change_variable = { which = prosperity_value value = 6 } }
				hills = { change_variable = { which = prosperity_value value = 6 } }
				coastal_desert = { change_variable = { which = prosperity_value value = 5 } }
				jungle = { change_variable = { which = prosperity_value value = 4 } }
				desert = { change_variable = { which = prosperity_value value = 4 } }
				marsh = { change_variable = { which = prosperity_value value = 3 } }
				mountain = { change_variable = { which = prosperity_value value = 2 } }
				impassable_mountains = { change_variable = { which = prosperity_value value = 2 } }
				arctic = { change_variable = { which = prosperity_value value = 2 } }
				wasteland = { change_variable = { which = prosperity_value value = 2 } }
				underempire = { change_variable = { which = prosperity_value value = 2 } }
			}

			if = { # Coastal provinces prosper quicker because they get more trade/disease
				limit = { port = yes any_province_holding = { holding_type = city } }
				change_variable = { which = prosperity_value value = 2 }
			}

			if = { # Coastal Mountains/Arctic, i.e. Aden, prosper quicker than non-coastal terrain of the same type
				limit = {
					port = yes
					any_province_holding = { holding_type = city }
					OR = { terrain = mountain terrain = arctic }
				}
				change_variable = { which = prosperity_value value = 4 }
			}

			if = { # Coastal Desert/Jungle, i.e. Mecca, prosper quicker than non-coastal terrain of the same type
				limit = {
					port = yes
					any_province_holding = { holding_type = city }
					OR = { terrain = desert terrain = jungle }
				}
				change_variable = { which = prosperity_value value = 2 }
			}
		}
		#Places of Power Math
		if = {
			limit = { has_province_modifier = active_place_of_power_man }
			reduce_doom_progress_tiny_effect = yes
		}
		if = {
			limit = { has_province_modifier = active_place_of_power_elf }
			reduce_doom_progress_tiny_effect = yes
		}
		if = {
			limit = { has_province_modifier = active_place_of_power_wood }
			reduce_doom_progress_minor_effect = yes
		}
		if = {
			limit = { has_province_modifier = corrupt_place_of_power_man }
			add_doom_progress_minor_effect = yes
		}
		if = {
			limit = { has_province_modifier = corrupt_place_of_power_elf }
			add_doom_progress_tiny_effect = yes
		}
		if = {
			limit = { has_province_modifier = corrupt_place_of_power_wood }
			add_doom_progress_minor_effect = yes
		}
		if = {
			limit = {
				has_province_flag = crown_focus_province #provinces with crown focus set gain a bonus 1-5 prosperity progress per year regardless of other factors
				NOR = { any_province_holding = { is_occupied = yes } has_disease = yes }
			}
			random_list = {
				10 = { change_variable = { which = prosperity_value value = 5 } }
				10 = { change_variable = { which = prosperity_value value = 4 } }
				10 = { change_variable = { which = prosperity_value value = 3 } }
				10 = { change_variable = { which = prosperity_value value = 2 } }
				10 = { change_variable = { which = prosperity_value value = 1 } }
			}
		}
		if = {
			limit = { has_province_flag = recent_depopulation_1 }
			change_variable = { which = prosperity_value value = 3 }
		}
		if = {
			limit = { has_province_flag = recent_depopulation_2 }
			change_variable = { which = prosperity_value value = 4 }
		}
		if = {
			limit = { has_province_flag = recent_depopulation_3 }
			change_variable = { which = prosperity_value value = 5 }
		}
		if = {
			limit = {
				check_variable = { which = prosperity_value value = 100 } #gain modifiers at 100/250/500 value
				NOR = {
					has_province_modifier = prosperity_modifier_1
					has_province_modifier = prosperity_modifier_2
					has_province_modifier = prosperity_modifier_3
				}
			}
			add_province_modifier = { name = prosperity_modifier_1 duration = -1 }
			owner = { character_event = { id = prosper.13 } }
			break = yes
		}
		if = {
			limit = {
				check_variable = { which = prosperity_value value = 250 }
				NOR = {
					has_province_modifier = prosperity_modifier_2
					has_province_modifier = prosperity_modifier_3
				}
			}
			remove_province_modifier = prosperity_modifier_1
			add_province_modifier = { name = prosperity_modifier_2 duration = -1 }
			owner = { character_event = { id = prosper.13 } }
			break = yes
		}
		if = {
			limit = {
				check_variable = { which = prosperity_value value = 500 }
				NOT = { has_province_modifier = prosperity_modifier_3 }
			}
			remove_province_modifier = prosperity_modifier_2
			add_province_modifier = { name = prosperity_modifier_3 duration = -1 }
			owner = { character_event = { id = prosper.13 } }
		}
	}
}

#
# The vanilla victory triumph (LoR.30 - LoR.32 in roman_events, never

#   triumph.4    The triumph is held

#   triumph.7    The cooldown ends (hidden)
#   triumph.10   The Emperor's triumph is expected (was LoR.30)
#   triumph.11   The Emperor's triumph is held (was LoR.31)
#   triumph.12   The Emperor's triumph (vassals, was LoR.32)
# Saved: character flags triumph_cooldown (five years), triumph_vs_chaos,
#   triumph_voice_<chaos|dwarf|greenskin|druchii|undead|skaven>,
#   triumph_guard_sworn (once per lifetime); event target triumph_foe;
#   unit earmark triumph_guard; opinion modifier opinion_triumph_held.
# Callers: common/on_actions/wh_on_actions.txt on_war_ended_victory (1),
#   on_war_ended_defeat (2).
# The Emperor's own holy-war triumph (triumph.10 - 12, fired by the holy

# triumph.1 An attacker wins (hidden)
# Scope: ROOT is the defender who lost, FROM the attacker who won.
character_event = {
	id = triumph.1
	hide_window = yes

	is_triggered_only = yes # on_war_ended_victory

	trigger = {
		higher_tier_than = COUNT
		NOT = { is_vassal_or_below = FROM }
		FROM = {
			is_alive = yes
			is_landed = yes
			prisoner = no
			NOT = { has_character_flag = triumph_cooldown }
			OR = { higher_tier_than = DUKE AND = { tier = DUKE independent = yes } }
		}
		OR = { higher_tier_than = DUKE realm_size = 15 }
	}

	immediate = {
		save_event_target_as = triumph_foe
		FROM = {
			set_character_flag = triumph_cooldown
			character_event = { id = triumph.7 days = 1825 }
			triumph_set_voice_effect = yes
			character_event = { id = triumph.3 days = 7 }
		}
	}
}

# Part 8: Lost lands reclaimed (namespace lostlands)
# Faction: Diplomacy & realms
# Serves: the Emperor, the Dawi High King, the Tomb Kings
#
# The vanilla lost Roman provinces (LoR.1 - LoR.40 in roman_events, never
# copied into the mod), moved to the great losses of the Warhammer world:
# the Wasteland that bought its freedom from Dieter IV, the Drakwald lost to
# the beastmen, Solland laid waste by Gorbad Ironclaw, and the Empire of
# Sigmar whole again; the lost holds of the Karaz Ankor (Eight Peaks, Karak
# Varn, Mount Gunbad, Karak Azgal, Karak Ungor) and the Karaz Ankor whole;
# and Nehekhara restored under the Tomb Kings. Each is news once per game
# for the player who reclaims it, with prestige. The de jure realms of
# Drakwald and Solland are restored by decision (wh_empire_decisions); this
# only marks the reconquest.
#   lostlands.1      The yearly check (hidden)
#   lostlands.2      Holds already in Dawi hands at the start (hidden)
#   lostlands.10-13  The Empire
#   lostlands.20-25  The Karaz Ankor
#   lostlands.30     Nehekhara
# Saved: global flags lostlands_<wasteland|drakwald|solland|empire_whole|
#   eight_peaks|karak_varn|gunbad|karak_azgal|karak_ungor|karaz_ankor_whole|
#   nehekhara_whole>, lostlands_start_checked.
# Callers: common/on_actions/wh_on_actions.txt on_yearly_pulse (1),
#   on_chronicle_start (2).
###############################################################################

			set_global_flag = lostlands_karak_varn

		}

			limit = {
				any_demesne_province = {
					debt_misrule_any_trigger = yes

			}
		}

			random_demesne_province = {

				save_event_target_as = misrule_mended
			}

		event_target:misrule_mended = {

# Part 12: Elective leagues
# Namespace: league (was DR_misc.1030 - 1046 in DR_misc_events.txt,
#   adapted from the Elective Leagues mod by JRuderman, all credit to him)
# Faction: Border Princes
# Serves: the small feudal lords of the Border Princes and anywhere else
#   that the faith allows elective rule
#
# Neighbouring free lords of equal rank may band together into a league:
# one founds a new duchy, kingdom or empire with feudal elective
# succession, and the neighbours whose lands touch the founder's (or touch
# another cofounder's) join as its electors. An AI league keeps inviting
# smaller free neighbours to join; a refusal sours the league's lord for a
# while.
#
# Founding a league                    league.1 - league.5
# Inviting a neighbour                 league.10 - league.11
#
# Callers: league.1 from on_yearly_pulse (00_on_actions.txt), league.2 also
#   from the decision create_elective_league (wh_general_decisions.txt);
#   league.10 from on_yearly_pulse (wh_on_actions.txt; was MTTH 1 year).
#   Triggers in wh_elective_leagues_scripted_triggers.txt, effects in
#   wh_elective_leagues.txt.
# Saved: variable num_cofounders; opinion modifiers opinion_cofounder and
#   rejected_league_prop.
# Loc: localisation/00_elective_leagues.csv
###############################################################################

namespace = league

# league.1 A league of equals
# Hidden. An AI count, duke or king of a faith that allows elective rule
# tries to found a league (league.2). Players use the decision.
# Scope: ROOT is an AI feudal ruler. Fired by on_yearly_pulse.
character_event = {
	id = league.1
	hide_window = yes

	is_triggered_only = yes # on_yearly_pulse

	ai = yes
	only_independent = yes

	trigger = {
		OR = { real_tier = KING real_tier = DUKE real_tier = COUNT }
		is_feudal = yes
		league_potential_trigger = yes
		religion_allows_feudal_elective_trigger = yes
	}

	immediate = {
		character_event = { id = league.2 }
	}
}

# league.2 Counting the cofounders
# Hidden. Counts the neighbours who would join (league.3), then offers the
# founder the new title (league.5).
# Scope: ROOT is the founder (league.1 or create_elective_league).
character_event = {
	id = league.2
	hide_window = yes

	is_triggered_only = yes # league.1, decision create_elective_league

	immediate = {
		set_variable = { which = num_cofounders value = 0 }
		character_event = { id = league.3 }
		character_event = { id = league.5 }
	}
}

# league.3 The neighbours
# Hidden. Every free lord of the same rank whose lands touch the founder's
# and who could join is marked as a cofounder.
# Scope: ROOT is the founder (league.2).
character_event = {
	id = league.3
	hide_window = yes

	is_triggered_only = yes # league.2

	immediate = {
		any_independent_ruler = {
			limit = {
				NOT = { character = ROOT }
				NOT = { reverse_has_opinion_modifier = { who = ROOT modifier = opinion_cofounder } }
				THIS_and_PREV_same_rank_trigger = yes
				THIS_can_join_PREV_league_trigger = yes
				THIS_and_ROOT_are_adjacent_trigger = yes
			}
			ROOT = { change_variable = { which = num_cofounders value = 1 } }
			reverse_opinion = { who = ROOT modifier = opinion_cofounder }
		}
	}
}

# league.5 A league is founded

				landless = no
				temporary = no
				custom_created = yes
				culture = ROOT
				holder = ROOT
				base_title = THIS
				copy_title_laws = yes
				name = ELECTIVE_REALM_NAME_DUKE
			}
		}
		create_league_effect = yes
		ai_chance = { factor = 90 }
	}
	option = {
		name = ElectiveLeagues_event_35_KINGDOM
		trigger = { tier = DUKE check_variable = { which = num_cofounders value = 1 } }
		primary_title = {
			create_title = {
				tier = KING
				landless = no
				temporary = no
				custom_created = yes
				culture = ROOT
				holder = ROOT
				base_title = THIS
				copy_title_laws = yes
				name = ELECTIVE_REALM_NAME_KING
			}

# league.10 The league grows
# Hidden. The AI lord of an elective league invites every smaller free
# neighbour who could join and has not refused lately (league.11).
# Scope: ROOT is an AI lord of a titular elective realm. Fired by
#   on_yearly_pulse (wh_on_actions).
character_event = {
	id = league.10
	hide_window = yes

	is_triggered_only = yes # on_yearly_pulse

	ai = yes
	only_independent = yes

	trigger = {
		higher_real_tier_than = COUNT
		in_revolt = no
		primary_title = { has_law = succ_feudal_elective is_titular = yes }
	}

	immediate = {
		any_independent_ruler = {
			limit = {
				NOT = { character = ROOT }
				league_potential_trigger = yes
				lower_real_tier_than = PREV
				THIS_can_be_elector_of_PREV_trigger = yes
				THIS_can_join_PREV_league_trigger = yes
				THIS_and_ROOT_are_adjacent_trigger = yes
				NOT = {
					has_opinion_modifier = { who = ROOT modifier = opinion_granted_independence }
				}
				NOT = {
					reverse_has_opinion_modifier = { who = ROOT modifier = rejected_league_prop }
				}
			}
			character_event = { id = league.11 }
		}
	}
}

		name = NOT_NOW

		}
	}

#   lordship_burgher, lordship_lord; province modifiers stop_commerce,

# Part 14: Vassal requests (namespace vassalreq)
# Namespace: vassalreq (was 63000 - 63102 in vassal_request_events.txt;
#   vassalreq.N is the old id minus 62900)
# Faction: Diplomacy & realms
# Serves: every feudal realm and its vassals

# Vassals ask their liege for things, and the liege answers with gold,
# favours, flattery or the dungeon:
#
#   A lesser vassal handed over (or a claim set against the asker)
#                                         vassalreq.100 - vassalreq.107
#   A rival denounced as a traitor        vassalreq.110 - vassalreq.120
#   Recompense for levies kept in the field (revived: vanilla had it off)
#                                         vassalreq.130 - vassalreq.135
#   A title from the liege's own demesne  vassalreq.140 - vassalreq.144
#   A friend in the dungeon pleads for help
#                                         vassalreq.150 - vassalreq.157
#   A mayor asks for lower city taxes (without Conclave only)
#                                         vassalreq.160 - vassalreq.165
#   Independence when the liege dies over the vassal limit
#                                         vassalreq.200 - vassalreq.202
#
# The starters were MTTH events on every character of the world (40, 80,
# 18, 40 and 167 years). They now roll from named lists, with the old MTTH
# modifiers turned into weight multipliers:
#   on_five_year_pulse vassal_requests (wh_on_actions.txt): 100 = 0,
#     15 = vassalreq.100, 7 = vassalreq.110, 15 = vassalreq.140,
#     3 = vassalreq.160;
#   on_yearly_pulse vassal_levy_complaints (wh_on_actions.txt): 100 = 0,
#     6 = vassalreq.130 (only while the liege has kept the vassal's levies
#     out for 73 days or more);
#   on_decade_pulse random_events (00_on_actions.txt): vassalreq.150;
#   on_over_vassal_limit_succession (00_on_actions.txt): vassalreq.200.
# Saved: character flags requested_vassal_transfer, vassal_for_favor,
#   requested_rival_removal, pleaded_innocence, requested_money_for_levies,
#   obj_gain_any_title_abandoned; event targets vassal_wanted_title,
#   rightful_liege.
# Loc: localisation/00_WHG_realm_events.csv
